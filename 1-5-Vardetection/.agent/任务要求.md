# 背景

当前文件夹是一个用于检测变异的流程。该流程尽管能正常运行，但是在远程服务器提交`lsf`文件时，我希望更细粒度执行任务。具体来说，在HPC上提交任务时，我希望每个脚本只分配1个cpu核心，然后一次提交多个任务。这样可以更高效地利用资源，避免单个任务占用过多核心导致资源浪费。

# 任务要求

创建一个总控`sh`脚本，运行该`sh`脚本的时候：

1. 可以将`conf`文件中的`样本列表`按照`split -l `的方式分割成多个小文件；
2. 对于每个小文件，生成一个对应的`lsf`提交脚本，脚本中调用原有的分析脚本，并且每个脚本只分配1个cpu核心；
3. 每个对应的`lsf`文件都要配备对应的`.conf`文件，确保每个任务都能正确读取参数；
4. 由人工手动提交所有生成的`lsf`脚本到HPC上执行。
