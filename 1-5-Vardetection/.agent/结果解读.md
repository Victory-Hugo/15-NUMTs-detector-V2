# 结果解读

`bed`文件是由脚本`1-检测变异-不一致断点.sh`产生的原始 NUMT 区间表合并结果。  
文件是 `tsv.gz` 格式，也就是“制表符分隔的压缩文本”，**没有表头**，每一行固定 4 列。

示例行：

```tsv
1000434_chr1.118141557.118142709|E100028702L1C001R02100510680	2584	2652	best_hit_to_mtDNA
```

## 每一列是什么意思

### 第 1 列：`numtID`

例子：

```text
1000434_chr1.118141557.118142709|E100028702L1C001R02100510680
```

通俗理解：这是这条候选 NUMT 序列的“名字”或“编号”。

通常可拆成两部分：

- `1000434_chr1.118141557.118142709`
  - 一般表示这条序列来自哪个候选核基因组区段。
  - 可理解为：样本中的一个候选插入区域，位于核基因组 `chr1:118141557-118142709` 附近。
- `E100028702L1C001R02100510680`
  - 一般是支持这条 contig / 序列的原始 read 或组装片段 ID。

所以第 1 列本质上是在回答：

**“这条记录说的是哪一条候选 NUMT 序列？”**

## 第 2 列：`numt_start`

例子：

```text
2584
```

通俗理解：这条候选 NUMT 序列，和线粒体参考序列比对后，**匹配起点**落在线粒体参考的第几个碱基。

这里的坐标是：

- 相对于 **mtDNA 参考序列**，不是核基因组坐标。
- 采用 **1-based** 计数，也就是第一个碱基记作 1。

所以 `2584` 的意思是：

**这条候选 NUMT 看起来对应线粒体参考序列从第 2584 位附近开始。**

## 第 3 列：`numt_end`

例子：

```text
2652
```

通俗理解：这条候选 NUMT 序列在线粒体参考上的**匹配终点**。

所以 `2584` 到 `2652` 连起来表示：

**这条候选 NUMT 大致对应 mtDNA 上的 2584 到 2652 这一段。**

如果想粗略估计对应片段长度，可以按下面理解：

```text
长度 ≈ numt_end - numt_start + 1
```

例如本行大约是：

```text
2652 - 2584 + 1 = 69 bp
```

## 第 4 列：`comment`

本文件中这一列目前看到的值都是：

```text
best_hit_to_mtDNA
```

通俗理解：这是一个备注标签，表示这条候选序列在比对时，**最佳命中目标是线粒体 DNA**。

也就是说，这条记录之所以被保留下来，是因为脚本认为它最像 mtDNA 的某一段，而不是别的参考序列位置。

这列本身不是数值统计，更像是一个“通过什么规则保留下来”的说明。

## 一整行应该怎样读

还是用这条记录举例：

```tsv
1000434_chr1.118141557.118142709|E100028702L1C001R02100510680	2584	2652	best_hit_to_mtDNA
```

可以直接读成：

**“有一条来自核基因组 `chr1:118141557-118142709` 候选区域的序列，它最像线粒体 DNA，并且对应线粒体参考序列的 2584 到 2652 区间。”**

## 这 4 列分别回答什么问题

- 第 1 列：是哪条候选 NUMT 序列？
- 第 2 列：它在线粒体参考上从哪里开始对应？
- 第 3 列：它在线粒体参考上到哪里结束？
- 第 4 列：为什么保留这条记录？

## 需要特别注意的几点

- 这个文件记录的是 **候选 NUMT 序列在线粒体参考上的对应区间**。
- 第 2、3 列是 **mtDNA 坐标**，**不是** 核基因组上的染色体坐标。
- 核基因组位置主要埋在第 1 列的 ID 字符串里，例如 `chr1.118141557.118142709`。
- 这个文件是一个**原始区间注释表**，主要作用是给后续变异分析提供区间信息。
- 如果后面看到带有 `ref`、`alt`、`human`、`chimp`、`age` 等字段的表，那已经是后续分析结果，不属于这个 `merge_bed` 文件本身。

## 这个文件在流程中的作用

该文件对应的原始生成逻辑来自`psl_to_numts_bed.py`。脚本会从 PSL 比对结果里挑出每条候选序列对 mtDNA 的最佳命中，然后输出这 4 列：

1. 候选序列 ID
2. 在线粒体参考上的起点
3. 在线粒体参考上的终点
4. 备注 `best_hit_to_mtDNA`

**“所有候选 NUMT 序列对应到 mtDNA 哪一段的索引表。”**
