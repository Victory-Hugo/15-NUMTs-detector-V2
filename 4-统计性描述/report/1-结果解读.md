# 方法与材料（中文）

本研究针对中国人群队列中的核基因组线粒体插入序列（NUMTs）进行了统计性描述，目标是从质控合格样本中概括 NUMTs 的长度分布、染色体插入位点分布以及人群频率结构。输入数据包括基础信息表、严格阈值下的高置信断点表和 `merge_bed` 长度信息表。基础信息表用于样本级质控筛选，其中样本 ID 列为 `ID`，质控状态列为 `质控状态`，仅保留标记为 `PASS` 的样本。配置文件记录的 meta 总样本数为 8,546，其中 8,376 个样本通过质控，170 个样本未纳入后续统计。

质控过滤后，研究分别对断点数据和长度数据进行了样本级保留。断点表来自 `3-confident_breakpoints.tsv.gz`，过滤后用于构建样本级 NUMT 事件表；`merge_bed` 表来自 `8-merge_bed.tsv.gz`，过滤后用于构建区域级长度统计表。断点过滤以 `sampleID` 为键，`merge_bed` 过滤则从记录键前缀中解析样本 ID。过滤结果显示，4,755,276 行断点记录中保留 4,017,482 行，76,418,787 行 `merge_bed` 记录中保留 63,765,079 行，表明主要分析建立在质控通过样本之上。

NUMT 长度统计基于过滤后的 `merge_bed` 文件完成。每一条记录由区域 ID 和比对到线粒体参考序列的起止坐标组成。程序先按区域 ID 汇总同一区域内的所有 hit，记录每个区域的 hit 数、最短长度、最长长度和中位长度；随后以该区域所有 hit 中的最大长度作为 `chosen_length`，用于区域级长度统计汇总。输出包括完整的区域级长度表和摘要表，其中摘要表报告区域数、`chosen_length` 的最小值、最大值、均值和中位数。需要说明的是，该长度定义反映的是在同一区域内观测到的最大支持片段长度，而非独立实验测得的单一插入真实长度。

插入位点分布分析基于过滤后的高置信断点表完成。程序要求断点表包含 `sampleID`、`source_region_chr`、`source_region_start` 和 `source_region_end` 四列，并以样本 ID 与源区域坐标的组合作为唯一样本级事件键，去除重复断点记录。对于每个唯一样本级事件，程序计算区间中点并输出事件表，同时汇总各染色体上的事件数，并生成适合核型图输入的区间文件。该步骤反映的是样本级事件在核基因组中的空间分布，而不是去重后的跨样本 distinct NUMT 数目。

distinct NUMT 的人群频率分析不再基于事件表的 1 kb 事件聚类，而是基于 `4-mt_disc_breakpoint_input.tsv.gz` 所代表的多样本原始输入进行跨样本聚类。程序首先按染色体分别对各样本事件中点进行排序，并按照最大间距 1,000 bp 的规则聚为同一跨样本 cluster；随后统计每个 cluster 的位置数、覆盖样本数、区间范围及区域长度摘要。频率按 `F = n / N` 计算，其中 `n` 为 cluster 所在样本数，`N` 设为 8,372。根据预设规则，`F >= 5%` 定义为 common，`1% <= F < 5%` 为 low-frequency，`0.1% <= F < 1%` 为 rare，`F < 0.1%` 为 ultra-rare；此外单样本、双样本和三样本 cluster 另行标记为 singleton、doubleton 和 tripleton。主结果采用 `min_sample_support = 1`，同时并行输出 `min_sample_support = 2-10` 的敏感性统计，用于评估 distinct NUMT 数目随支持样本阈值变化的稳定性。

软件执行流程由 Bash 总控脚本驱动，调用 Python 脚本完成样本过滤、长度表构建、事件表构建和跨样本 cluster 频率统计，并调用 R 脚本绘制核型图与 cluster 分布图。配置中记录运行环境为 conda 环境 `BigLin`，线程数为 8，分块大小为 1,000,000 行。由于当前输出目录未直接给出 Python、R 及各依赖包的具体版本号，本报告不补造版本信息；同样，当前结果目录未提供分组比较、协变量建模或显著性检验输出，因此本文仅进行描述性统计解释，不对群体差异、因果关系或临床关联作超出证据边界的推断。

# Methods and Materials (EN)

This study provided a statistical description of nuclear mitochondrial DNA segments (NUMTs) in a Chinese population cohort, with the aim of summarizing NUMT length distribution, chromosomal insertion-site distribution, and population frequency structure among quality-controlled samples. Input data included a metadata table, a high-confidence breakpoint table generated under a strict threshold, and a `merge_bed` table containing length-related information. The metadata table was used for sample-level quality control, where the sample ID column was `ID`, the QC status column was `质控状态`, and only samples labeled `PASS` were retained. According to the configuration file, 8,546 samples were listed in the metadata table, of which 8,376 passed QC and 170 were excluded from downstream summaries.

After QC filtering, breakpoint and length-related tables were subset at the sample level. The breakpoint data came from `3-confident_breakpoints.tsv.gz` and were used to construct sample-level NUMT event tables after filtering. The `merge_bed` data came from `8-merge_bed.tsv.gz` and were used to construct region-level length summaries after filtering. Breakpoint filtering used `sampleID` directly, whereas `merge_bed` filtering parsed the sample ID from the prefix of each record key. A total of 4,017,482 rows were retained from 4,755,276 breakpoint rows, and 63,765,079 rows were retained from 76,418,787 `merge_bed` rows, indicating that the main analysis was restricted to QC-passing samples.

NUMT length statistics were derived from the filtered `merge_bed` file. Each record contained a region ID and the start and end coordinates of a read segment aligned to the mitochondrial reference. The program first grouped all hits belonging to the same region ID and recorded the number of hits, minimum length, maximum length, and median length per region. It then used the maximum observed hit length within each region as `chosen_length` for downstream region-level summaries. Outputs included a complete region-level length table and a summary table reporting the number of regions as well as the minimum, maximum, mean, and median of `chosen_length`. This definition reflects the maximum supported fragment length observed within a region rather than a single experimentally validated insertion length.

Insertion-site distribution analysis was based on the filtered high-confidence breakpoint table. The program required the columns `sampleID`, `source_region_chr`, `source_region_start`, and `source_region_end`, and defined a unique sample-level event by the combination of sample ID and source-region coordinates to remove redundant breakpoint rows. For each unique sample-level event, the midpoint of the interval was calculated and written to an event table; chromosome-level event counts were also summarized, and an interval file suitable for ideogram plotting was generated. This step therefore captures the genomic distribution of sample-level events rather than the number of cross-sample distinct NUMTs.

Population-frequency analysis of distinct NUMTs was not performed on the event table. Instead, it used the multi-sample raw input represented by `4-mt_disc_breakpoint_input.tsv.gz` to build cross-sample clusters. Events were sorted by chromosome and midpoint, and positions within a maximum gap of 1,000 bp were grouped into the same cross-sample cluster. For each cluster, the number of positions, number of supporting samples, genomic span, and region-length summary were recorded. Frequency was calculated as `F = n / N`, where `n` is the number of samples carrying a cluster and `N` was set to 8,372. According to the predefined scheme, clusters were classified as common when `F >= 5%`, low-frequency when `1% <= F < 5%`, rare when `0.1% <= F < 1%`, and ultra-rare when `F < 0.1%`. Single-sample, two-sample, and three-sample clusters were additionally labeled as singleton, doubleton, and tripleton. The primary results used `min_sample_support = 1`, while parallel outputs for `min_sample_support = 2-10` were generated as a sensitivity analysis to evaluate how the number of distinct NUMTs changed with support thresholds.

The computational workflow was orchestrated by a Bash driver script that called Python scripts for sample filtering, length-table construction, event-table construction, and cross-sample frequency clustering, and R scripts for ideogram and cluster-distribution plots. The configuration recorded the conda environment as `BigLin`, the thread count as 8, and the chunk size as 1,000,000 rows. Because the current output directory did not directly provide exact versions of Python, R, or dependency packages, this report does not invent software version details. Likewise, because the result directory did not include group comparisons, covariate modeling, or formal hypothesis-testing outputs, the present interpretation is limited to descriptive statistics and does not extend to unsupported inferences on group effects, causality, or clinical association.

# 结果（中文）

## R01. 质控过滤结果

基础信息表共记录 8,546 个样本，其中 8,376 个样本通过质控，整体通过率为 98.01%。在断点数据中，共观察到 9,798 个样本 ID，过滤后保留 8,372 个实际出现在断点表中的 PASS 样本，删除 1,426 个样本；对应断点行数从 4,755,276 行下降到 4,017,482 行，保留比例为 84.48%。在 `merge_bed` 数据中，共观察到 6,872 个样本 ID，过滤后保留 5,706 个 PASS 样本，删除 1,166 个样本；对应记录数从 76,418,787 行降至 63,765,079 行，保留比例为 83.44%。

这些结果表明，后续统计是在较高样本保留率的基础上完成的，基础样本框架较稳定。与此同时，断点表与 `merge_bed` 表中观测样本数并不完全一致，提示不同上游文件对样本的覆盖范围存在差异，因此不同结果模块的分母和样本可见性不能简单互换。由于当前输出仅提供过滤前后计数，未提供被过滤样本在疾病状态、民族或地理来源上的结构信息，因此无法判断质控剔除是否引入系统性群体偏倚。

## R02. NUMT 长度分布

区域级长度统计共得到 111,487 个 NUMT 区域。以每个区域内观测到的最大支持片段长度作为 `chosen_length` 后，NUMT 长度最短为 29 bp，最长为 16,568 bp，均值为 350.38 bp，中位数为 111 bp。四分位数显示该分布明显右偏：25%、50% 和 75% 分位数分别为 79 bp、111 bp 和 127 bp，而 90% 分位数迅速升至 497 bp，95% 分位数为 611 bp，99% 分位数达到约 8,012.56 bp。进一步计数显示，92,373 个区域（82.86%）长度小于 200 bp，仅 3,407 个区域（3.06%）达到或超过 1,000 bp，2,216 个区域（1.99%）达到或超过 5,000 bp。

这一模式说明，中国人群队列中的大多数 NUMT 区域以短片段为主，但同时存在数量有限、长度明显延展的长尾事件。由于均值显著高于中位数，且高分位数跃升明显，少数超长区域对总体均值有较强拉动作用。结合区域内 hit 数分布可见，中位 hit 数为 14，而 90% 分位数已增至 671，提示部分区域可能积累了非常密集的支持信号。需要强调的是，本分析采用的是区域内最大 hit 长度作为代表值，因此结果更适合描述“可观测支持上界”而非精确定义插入片段的生物学真实长度。

## R03. NUMT 插入位点的染色体分布

断点去重后共得到 123,863 个唯一样本级 NUMT 事件，说明原始断点表中的多行记录被有效归并为区域级事件。NUMT 事件广泛分布于常染色体和性染色体，但分布并不均匀。事件数最高的染色体为 chr1（17,519，14.14%）和 chr2（17,039，13.76%），随后依次为 chr11（10,869，8.78%）、chr17（9,716，7.84%）、chr5（8,211，6.63%）和 chr4（8,040，6.49%）。相比之下，chr19（155）、chr18（798）和 chr22（895）上的事件较少，提示 NUMT 插入热点在不同染色体间存在明显异质性。

如果从区域级长度表观察染色体承载的区域数，chr2、chr1、chr11、chr17 和 chr4 仍位居前列，与事件计数层面的总体格局较为一致，说明高事件染色体并非仅由个别超高重复样本驱动，而更可能反映这些染色体上存在更频繁或更易被检测到的 NUMT 区域。R 端核型图和热图输出为这一非均匀性提供了可视化支持。不过，当前结果目录缺少按染色体长度标准化后的事件密度、重复序列背景或基因组可比对性校正，因此本研究只能确认“观测到的分布不均匀”，尚不能进一步断言这种不均匀性完全源于真实生物学插入偏好。

## R04. distinct NUMT 的总体频率结构

在 `min_sample_support = 1` 的主分析中，共识别 2,835 个 distinct NUMT clusters。其支持样本数分布同样高度偏斜：25%、50% 和 75% 分位数分别为 1、2 和 6 个样本，说明至少一半的 distinct NUMT 仅出现在不超过 2 个样本中；但上尾较长，90% 分位数达到 63 个样本，95% 分位数约为 308.7 个样本，99% 分位数约为 3,071.84 个样本。换算为样本频率后，中位频率约为 0.020%，75% 分位数约为 0.061%，而 99% 分位数可达 31.27%，提示人群中的 distinct NUMT 同时包含大量极低频事件和少数高度共享事件。

按预设频率等级划分，ultra-rare cluster 有 2,244 个，占全部 distinct NUMTs 的 79.15%；rare cluster 为 354 个，占 12.49%；low-frequency cluster 为 119 个，占 4.20%；common cluster 为 118 个，占 4.16%。这一结果表明，该队列中的 distinct NUMT 频谱以极低频变异为主，真正达到 common 水平的 cluster 数量有限。由于 singleton、doubleton 和 tripleton 也包含在 ultra-rare 范畴内，因此超低频层级既包含真正的个体特异事件，也包含少量低度复发事件。该结构与结构变异研究中常见的“长尾频率谱”一致，但当前数据仅支持描述其分层现象，尚不足以判断这些 ultra-rare 事件分别对应新近插入、技术边界效应还是人群历史累积所致。

## R05. 频率阈值敏感性与低频成分贡献

支持样本阈值分析进一步揭示了低频成分对 distinct NUMT 总量的主导作用。当最低支持阈值从 1 提高到 2 时，distinct NUMT 数量由 2,835 降至 1,450，减少 1,385 个，恰好对应所有 singleton clusters；当阈值继续提高到 3 时，总数进一步降至 1,079，又减少 371 个，对应全部 doubleton clusters；提高到 4 时，总数为 909，再减少 170 个，对应全部 tripleton clusters。随后阈值从 4 增加到 10，distinct NUMT 数量从 909 逐步降至 591，下降幅度明显放缓。

这一结果说明，主分析中的 distinct NUMT 总数对最小样本支持阈值较为敏感，且敏感性主要集中在单样本到三样本支持的超低频区间。一旦剔除 singleton、doubleton 和 tripleton 后，保留下来的 cluster 集合相对稳定，例如至少在 10 个样本中出现的 cluster 仍有 591 个，在 20、50 和 100 个样本中出现的 cluster 分别还有 443、304 和 237 个。这表明该队列中既存在大量个体或极低频 NUMT，也存在一组在不同样本间反复观测到的稳定复发事件。局限在于，当前敏感性分析只改变了支持样本阈值，未同时评估不同聚类间距、不同分母定义或不同质控策略对结果的影响。

## R06. 高复发 distinct NUMT 热点

最常见的复发 cluster 位于 chr17，对应 `18_chr17`，共有 9,822 个样本支持，频率为 99.99%，几乎覆盖全部纳入频率分析的样本。其后为 chr1 上的 `1_chr1`（7,947 个样本，80.90%）、chr11 上的 `47_chr11`（6,776 个样本，68.98%）、chr5 上的 `27_chr5`（6,120 个样本，62.30%）和 chr2 上的 `35_chr2`（5,984 个样本，60.92%）。这些热点均属于 common 类别，且对应区间长度从 1,731 bp 到 7,572 bp 不等，提示高频共享 NUMT 并不局限于单一长度尺度。

这些极高复发 cluster 很可能构成该队列中最稳定、最具代表性的 NUMT 热点区域，并对总体频率分层的 common 端起决定性作用。与此同时，热点 cluster 的高度共享也提示需要谨慎区分真实高频 NUMT、参考基因组背景、比对复杂区域以及可能的技术性富集因素。由于当前输出缺乏与公共数据库、家系信息或独立验证实验的交叉比对，本研究只能确认这些位点在本队列中具有极强复发性，而不能单凭描述性统计判断其形成机制或进化来源。

# Results (EN)

## R01. Quality-control filtering

The metadata table contained 8,546 samples, of which 8,376 passed quality control, corresponding to an overall pass rate of 98.01%. In the breakpoint data, 9,798 sample IDs were observed; after filtering, 8,372 QC-passing samples remained in the breakpoint table and 1,426 were removed. The number of breakpoint rows decreased from 4,755,276 to 4,017,482, a retention rate of 84.48%. In the `merge_bed` data, 6,872 sample IDs were observed; after filtering, 5,706 QC-passing samples were retained and 1,166 were removed. The number of `merge_bed` records decreased from 76,418,787 to 63,765,079, a retention rate of 83.44%.

These results indicate that downstream summaries were performed on a dataset with a high overall sample-retention rate. At the same time, the number of observed samples differed between the breakpoint and `merge_bed` tables, suggesting that upstream files did not cover exactly the same sample set. The denominators and observable samples therefore cannot be directly interchanged across result modules. Because the current outputs only provide before-and-after counts, without disease-status, ethnicity, or geographic composition of excluded samples, it is not possible to determine whether QC filtering introduced systematic population bias.

## R02. NUMT length distribution

Region-level length analysis yielded 111,487 NUMT regions. When the maximum observed hit length within each region was used as `chosen_length`, the shortest NUMT was 29 bp, the longest was 16,568 bp, the mean was 350.38 bp, and the median was 111 bp. Quartiles showed a strongly right-skewed distribution: the 25th, 50th, and 75th percentiles were 79 bp, 111 bp, and 127 bp, respectively, whereas the 90th percentile increased sharply to 497 bp, the 95th percentile reached 611 bp, and the 99th percentile was approximately 8,012.56 bp. Additional counting showed that 92,373 regions (82.86%) were shorter than 200 bp, only 3,407 regions (3.06%) were at least 1,000 bp, and 2,216 regions (1.99%) were at least 5,000 bp.

This pattern indicates that most NUMT regions in the Chinese cohort were short, while a limited number of long-tail events extended to much greater lengths. The mean being substantially larger than the median, together with the rapid increase at high percentiles, shows that a small number of very long regions strongly influenced the overall mean. The distribution of per-region hit counts supports this view: the median hit count was 14, whereas the 90th percentile had already increased to 671, suggesting that some regions accumulated extremely dense supporting signals. Importantly, this analysis used the maximum hit length within each region as the representative value, so it is better interpreted as an upper bound of observable support rather than the exact biological insertion length.

## R03. Chromosomal distribution of NUMT insertion sites

After deduplication of breakpoint rows, 123,863 unique sample-level NUMT events were obtained, indicating that multiple raw breakpoint rows were effectively consolidated into region-level events. NUMT events were broadly distributed across autosomes and sex chromosomes, but the distribution was clearly non-uniform. The highest event counts were observed on chr1 (17,519; 14.14%) and chr2 (17,039; 13.76%), followed by chr11 (10,869; 8.78%), chr17 (9,716; 7.84%), chr5 (8,211; 6.63%), and chr4 (8,040; 6.49%). By contrast, chr19 (155), chr18 (798), and chr22 (895) showed relatively few events, indicating marked heterogeneity in observed NUMT hotspots across chromosomes.

When the region-level length table was examined, chr2, chr1, chr11, chr17, and chr4 also ranked among the leading chromosomes by region count, broadly consistent with the event-count pattern. This consistency suggests that the chromosomes with high event burdens were not driven solely by a few highly repeated samples, but more likely reflect chromosomes that harbor more frequently observed or more readily detectable NUMT regions. The ideogram and heatmap outputs from the R workflow visually support this non-uniformity. However, because the current result set does not include normalization by chromosome length, repeat content, or mappability, the present analysis can only conclude that the observed distribution is uneven; it cannot determine whether the pattern is entirely due to true biological insertion preference.

## R04. Global frequency structure of distinct NUMTs

In the primary analysis with `min_sample_support = 1`, a total of 2,835 distinct NUMT clusters were identified. Their supporting-sample counts were also highly skewed: the 25th, 50th, and 75th percentiles were 1, 2, and 6 samples, respectively, indicating that at least half of all distinct NUMTs were present in no more than two samples. However, the upper tail was long, with the 90th percentile reaching 63 samples, the 95th percentile approximately 308.7 samples, and the 99th percentile approximately 3,071.84 samples. After conversion to sample frequency, the median frequency was about 0.020%, the 75th percentile about 0.061%, and the 99th percentile as high as 31.27%, indicating coexistence of many extremely low-frequency events and a small number of highly shared events.

According to the predefined frequency classes, 2,244 clusters were ultra-rare, accounting for 79.15% of all distinct NUMTs; 354 were rare (12.49%); 119 were low-frequency (4.20%); and 118 were common (4.16%). These results show that the frequency spectrum of distinct NUMTs in this cohort was dominated by extremely low-frequency variants, whereas only a limited number of clusters reached the common range. Because singleton, doubleton, and tripleton clusters are included within the ultra-rare category, the ultra-rare layer contains both individual-specific events and mildly recurrent events. This structure is consistent with the long-tailed spectra commonly seen in structural-variation studies, but the current data only support description of the pattern and do not allow discrimination among recent insertions, technical boundary effects, or accumulated population history as the underlying source of ultra-rare events.

## R05. Sensitivity to support thresholds and contribution of low-frequency components

The support-threshold analysis further demonstrated that low-frequency components dominated the total number of distinct NUMTs. When the minimum support threshold increased from 1 to 2, the number of distinct NUMTs decreased from 2,835 to 1,450, a reduction of 1,385 clusters, exactly matching all singleton clusters. When the threshold increased further to 3, the total decreased to 1,079, removing an additional 371 clusters, corresponding to all doubleton clusters. At a threshold of 4, the total dropped to 909, removing another 170 clusters, corresponding to all tripleton clusters. Beyond this point, increasing the threshold from 4 to 10 reduced the total from 909 to 591, with a substantially slower decline.

These results show that the total distinct NUMT count in the primary analysis was highly sensitive to the minimum support threshold, and that this sensitivity was concentrated in the ultra-low-frequency range of one to three supporting samples. Once singleton, doubleton, and tripleton clusters were excluded, the remaining cluster set became relatively stable. For example, 591 clusters were still observed in at least 10 samples, and 443, 304, and 237 clusters remained at thresholds of 20, 50, and 100 samples, respectively. This indicates that the cohort contains both many individual or extremely rare NUMTs and a core set of repeatedly observed recurrent events. A limitation is that this sensitivity analysis varied only the support threshold and did not evaluate alternative clustering gaps, denominator definitions, or QC strategies.

## R06. Highly recurrent distinct NUMT hotspots

The most recurrent cluster was `18_chr17` on chr17, supported by 9,822 samples and having a frequency of 99.99%, thus covering nearly the entire sample set used for frequency analysis. It was followed by `1_chr1` on chr1 (7,947 samples; 80.90%), `47_chr11` on chr11 (6,776 samples; 68.98%), `27_chr5` on chr5 (6,120 samples; 62.30%), and `35_chr2` on chr2 (5,984 samples; 60.92%). All of these hotspots belonged to the common class, and their chosen region lengths ranged from 1,731 bp to 7,572 bp, indicating that highly shared NUMTs were not restricted to a single length scale.

These highly recurrent clusters likely represent the most stable and most representative NUMT hotspot regions in the cohort, and they strongly shape the common end of the overall frequency spectrum. At the same time, their extreme recurrence underscores the need to distinguish true high-frequency NUMTs from reference-background effects, alignment complexity, and possible technical enrichment. Because the current outputs do not include cross-validation against public databases, pedigree information, or independent validation experiments, the present study can only conclude that these loci are strongly recurrent within this cohort and cannot infer their formation mechanism or evolutionary origin from descriptive statistics alone.

# 讨论（中文）

本次统计性描述显示，中国人群队列中的 NUMT 图谱具有三个彼此关联的核心特征。第一，长度分布以短片段为主，而少数超长事件构成明显长尾；第二，插入位点在染色体间呈现强烈不均匀分布；第三，distinct NUMT 的人群频谱以 ultra-rare 事件占主导，同时保留一小组在大量样本中重复出现的 common 热点。三者结合表明，NUMT 在群体中的表现并不是单一尺度上的随机现象，而更像是由大量低频、局部化事件叠加少数稳定高复发位点共同构成的复合结构。

从长度结果看，中位数仅为 111 bp，而均值升至 350.38 bp，说明主体群体由短 NUMT 构成，但总体统计受少量长片段显著牵引。这种模式可能意味着多数可检测 NUMT 仅保留较短的线粒体来源片段，或者当前检测流程更容易稳定识别短而边界清晰的插入；另一方面，极少数长片段区域的存在提示部分位点可能承载更完整的线粒体来源序列或更复杂的局部结构。由于本流程用区域内最大 hit 长度表示区域长度，因此这些长尾区域尤其值得在后续分析中通过原始比对、局部组装或独立实验进一步验证。

从空间分布看，chr1、chr2、chr11 和 chr17 等染色体同时在事件数和区域数上位居前列，支持 NUMT 分布存在明显热点化趋势。这一现象可能与染色体长度、重复序列环境、染色质开放状态、断裂修复机会或参考基因组可比对性等多种因素共同相关。但由于当前分析未做长度归一化，也未联合重复序列、基因密度或复制时序等注释信息，因此这些机制解释仍然停留在假设层面。更稳健的下一步应是计算每 Mb 事件密度、按染色体可比对区域归一化，并与重复序列和结构变异背景进行重叠分析。

从人群频谱看，79.15% 的 distinct NUMTs 属于 ultra-rare，而 common 类别仅占 4.16%，提示该队列中的 NUMT 多数为个体特异或极低复发事件。这种频谱既可能反映真实的人群异质性，也可能受到聚类口径、断点检测边界和样本覆盖差异的影响。值得注意的是，当最小支持阈值从 1 提升到 4 后，distinct NUMT 数目由 2,835 快速降至 909，说明超低频层级对总量贡献极大；但即使在更严格阈值下，仍有数百个 cluster 保持稳定存在，说明该队列并非只有离散的个体事件，还包含一批跨样本复发的核心 NUMT 位点。

其中，chr17、chr1、chr11、chr5 和 chr2 上的若干 common 热点显示出极高的样本覆盖率，尤其 chr17 上的主热点几乎覆盖全部分析样本。这些位点具有潜在的生物学和技术双重意义：一方面，它们可能代表中国人群中稳定存在的常见 NUMT 背景；另一方面，它们也可能与参考序列结构、比对歧义或上游 calling 规则相关。因此，在将这些高频位点用于群体比较、疾病关联或过滤黑名单之前，必须先进行更高层级的注释与验证，例如与已知公共 NUMT 位点比对、查看局部序列复杂性，并检验不同平台和不同 pipeline 下的复现性。

本研究的主要局限在于其本质上是描述性分析。当前结果目录未提供分组信息与结局关联的统计检验，也未提供软件版本、技术重复、实验验证或外部数据集对照，因此不能将这些结果直接解释为疾病相关机制或人群进化结论。此外，distinct NUMT 的定义依赖 1 kb 聚类规则，不同间距阈值可能影响低频 cluster 的拆分和合并；长度统计使用最大 hit 长度，也可能高估部分区域的代表长度。尽管如此，本分析仍为后续工作建立了清晰的经验基础，即中国人群 NUMT 景观具有短片段主导、染色体分布不均和频率长尾显著三大特征，可据此进一步开展标准化密度分析、群体分层比较和高频热点验证。

# Discussion (EN)

This statistical description indicates that the NUMT landscape in the Chinese cohort has three interrelated core features. First, the length distribution is dominated by short fragments, with a pronounced long tail formed by a minority of very long events. Second, insertion sites are strongly uneven across chromosomes. Third, the population frequency spectrum of distinct NUMTs is dominated by ultra-rare events while also retaining a small set of highly recurrent common hotspots. Taken together, these features suggest that NUMTs in the cohort do not follow a single-scale random pattern, but instead form a composite structure consisting of numerous low-frequency localized events plus a limited number of stable recurrent loci.

From the length perspective, the median was only 111 bp whereas the mean reached 350.38 bp, indicating that the bulk of the distribution consists of short NUMTs but the overall summary is strongly influenced by a small number of long fragments. This pattern may imply that most detectable NUMTs retain only short mitochondrial-derived segments, or that the current pipeline more reliably detects short insertions with clearer boundaries. At the same time, the presence of a few very long regions suggests that some loci may harbor more complete mitochondrial-derived segments or more complex local structures. Because this workflow uses the maximum hit length within a region as the representative region length, these long-tail regions warrant follow-up validation using raw alignments, local assembly, or independent assays.

From the spatial perspective, chr1, chr2, chr11, and chr17 ranked highly in both event counts and region counts, supporting the presence of hotspot-like clustering of NUMTs across the genome. This pattern may relate to chromosome size, repeat-sequence environment, chromatin accessibility, opportunities for DNA break repair, or reference-genome mappability. However, because the current analysis did not normalize by chromosome length and did not integrate repeat annotation, gene density, or replication timing, these mechanistic interpretations remain hypothetical. A more robust next step would be to calculate event density per megabase, normalize by callable genomic regions, and examine overlap with repeats and structural-variation backgrounds.

From the population-frequency perspective, 79.15% of distinct NUMTs were ultra-rare whereas only 4.16% were common, indicating that most NUMTs in this cohort are individual-specific or minimally recurrent. This spectrum may reflect true population heterogeneity, but it may also be shaped by clustering rules, breakpoint-detection boundaries, and differences in sample coverage. Notably, when the minimum support threshold was increased from 1 to 4, the number of distinct NUMTs dropped rapidly from 2,835 to 909, showing that the ultra-low-frequency layer contributes substantially to the total count. Nevertheless, several hundred clusters remained even under stricter thresholds, indicating that the cohort contains not only isolated individual events but also a core set of recurrent NUMT loci shared across samples.

Among these, several common hotspots on chr17, chr1, chr11, chr5, and chr2 showed extremely high sample coverage, with the leading chr17 hotspot covering nearly all analyzed samples. These loci are potentially important in both biological and technical terms. On one hand, they may represent stable common NUMT backgrounds in the Chinese population. On the other hand, they may also reflect reference-sequence structure, alignment ambiguity, or characteristics of the upstream calling procedure. Therefore, before these high-frequency loci are used for population comparison, disease association, or blacklist filtering, they should undergo higher-level annotation and validation, including comparison with known public NUMT loci, inspection of local sequence complexity, and testing for reproducibility across platforms and pipelines.

The main limitation of this study is that it is inherently descriptive. The current result directory does not provide formal association tests with group labels or outcomes, nor does it provide software versions, technical replicates, experimental validation, or external reference datasets. Accordingly, these findings cannot be directly interpreted as disease-related mechanisms or evolutionary conclusions. In addition, the definition of distinct NUMTs depends on a 1 kb clustering rule, and different gap thresholds may affect splitting and merging of low-frequency clusters. The length summary is based on maximum hit length and may therefore overestimate the representative length of some regions. Even with these limitations, the present analysis establishes a clear empirical baseline: the NUMT landscape in this Chinese cohort is characterized by short-fragment predominance, uneven chromosomal distribution, and a strongly long-tailed frequency spectrum. This baseline provides a rational starting point for subsequent normalized density analysis, population-stratified comparisons, and validation of recurrent hotspots.
