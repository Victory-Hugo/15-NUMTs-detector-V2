# 背景介绍

NUMTs是指线粒体DNA片段插入到核基因组中的现象。
本研究对中国人群队列的NUMTs进行了探索。
本文件夹负责**NUMTs的统计性描述**，包括NUMTs的长度分布、插入位点分布。

# 任务

任务是：

1. 对不符合质控措施的样本进行过滤，保留符合质控措施的样本（基于基础信息表），保留的文件放在`/mnt/f/Onedrive/文档（科研）/脚本/Download/15-NUMTs-detector-V2/4-统计性描述/tmp`。
2. 统计NUMTs的**长度分布**（基于`8-merge_bed.tsv.gz`）+ 可视化。
   1. 可视化结果可以多样化。最重要的图形需要X轴为NUMTs长度，Y轴为频率的柱状图，分箱可以根据实际数据分布进行调整。
3. 统计NUMTs的**插入位点分布**（基于`3-confident_breakpoints.tsv.gz`）+ 可视化。
   1. 最好使用染色体核型图（ideogram）必须使用R语言可视化。可参照`/mnt/f/Onedrive/文档（科研）/脚本/Download/15-NUMTs-detector-V2/3-可视化NUMTs分布/2-Ideogram/script/2-NUMTs分布.R`中的方法进行可视化。
4. 统计NUMTs在人群中的分布频率（基于`3-confident_breakpoints.tsv.gz`），并可视化
   1. 需要采用如下规则计算：
      1. **common**：$F \ge 5%$
      2. **low-frequency**：$1% \le F < 5%$
      3. **rare**：$0.1% \le F < 1%$
      4. **ultra-rare**：$F < 0.1%$
      5. **singleton**：只在 1 个人中检出。singleton 包含在 ultra-rare 里面。
      6. **doubleton**：在 2 个人中检出。doubleton 包含在 ultra-rare 里面。
      7. **tripleton**：在 3 个人中检出。tripleton 包含在 ultra-rare 里面。

# 数学

**NUMT 频率 $F$ 实际上就是该 distinct NUMT 在样本中的检出比例**：

$$
F=\frac{n}{N}
$$

其中：

* $n$ = 携带该 **distinct NUMT** 的样本数
* $N$ = 纳入 NUMT 分析的总样本数
