# Landscape of Nuclear Mitochondrial DNA Segments in a Multi-Population Cohort of 8,376 Individuals

## 重新组织后文本 (中文)

### 摘要

**背景：** 核线粒体DNA片段（NUMTs）是线粒体DNA在进化过程中整合至核基因组的片段。尽管近期大规模研究已开始描绘人类NUMT全景，但人群特异性模式——尤其在东亚人群中——仍未得到充分表征。

**方法：** 本研究采用经认证的短读长NUMT检测流程（要求≥5对discordant reads），对8,376例质控合格样本的全基因组测序数据进行分析，样本涵盖公共参考人群（1000 Genomes Project、HGDP、SGDP）及本队列新招募样本。NUMTs按群体频率分为常见（≥0.05%）、低频（0.05%–0.01%）、稀有（0.01%–0.001%）和超稀有（<0.001%）四类，并排除已知参考NUMTs以鉴定新发插入事件。

**结果：** 本研究共鉴定111,487个distinct NUMT区域，归属2,835个cluster。超稀有NUMTs占主导地位（79.15%），与持续插入和负向选择模型一致。每位个体平均携带14.79个NUMTs（标准差 = 9.84）。排除已知参考NUMTs后，剩余17,181个distinct区域（占总数的15.4%），其中16个为队列特异性常见插入事件，此前未被收录。新招募队列样本表现出显著更高的超稀有NUMT比例（93.73% vs. 全队列79.15%）和更低的每样本NUMT负荷（均值4.36 vs. 14.79），在严格阈值下47.28%的样本未检出可检测的NUMTs。复发频率最高的NUMT（chr17:22519788–22531705）存在于99.99%的个体中。NUMT长度与群体频率呈反向关系（常见事件中位数为111 bp，新发事件中位数为67 bp）。染色体分布呈非随机模式，在1号、2号、11号和17号染色体上显著富集。

**结论：** 本研究系统刻画了多人群队列中NUMT频率分布的全景特征，证实人类NUMT景观的高度保守性，同时鉴定了人群特异性插入事件。这些发现为未来研究NUMTs的功能和临床意义提供了参考资源。

### 引言

线粒体DNA向核基因组的转移是一个持续的进化过程，已塑造真核生物基因组数亿年之久。核线粒体DNA片段（NUMTs）——整合至核染色体的mtDNA片段——在所有真核物种中普遍存在，作为分子化石记录了基因组间DNA转移的历史。在人类中，NUMTs的长度从数个碱基对到近乎完整的线粒体基因组（16,569 bp），其累积速率估计约为每10⁴次出生发生一次插入。

NUMTs研究近年来重新受到关注，原因有三。首先，NUMTs代表一种潜在的基因组变异来源，可能导致基因 disruption、基因表达改变和基因组不稳定。NUMT插入已与多种人类疾病相关，包括IV型黏脂贮积症、Pallister-Hall综合征及多种癌症。其次，NUMTs可在下一代测序数据中产生假异质性信号，从而干扰线粒体基因组分析，因此准确表征NUMTs对于线粒体基因组研究至关重要。第三，NUMTs在核基因组中的非随机分布为介导线粒体-核DNA转移的DNA修复和反转录转座机制提供了重要线索。

近期大规模研究已开始系统编目人类群体中的NUMTs。Wei等（2022）分析了100,000 Genomes Project的全基因组测序数据，在≥5对discordant reads的检测阈值下鉴定出254,195个NUMT事件（1,637个distinct NUMTs）。他们证实NUMTs在核基因组中呈非随机分布，插入长度与群体频率之间存在反向关系，并表现出族群特异性模式。然而，这些研究主要基于欧洲裔人群，东亚及其他代表性不足人群中的NUMT景观仍未得到充分刻画。

本研究对8,376例质控合格样本的NUMT频率分布进行了全面分析，整合了公共参考数据（1000 Genomes Project、Human Genome Diversity Project、Simons Genome Diversity Project）与本队列新招募样本。利用经认证的短读长NUMT检测流程，我们跨频率类别表征了NUMT景观，比较了参考样本与新发样本之间的模式差异，并鉴定了此前未被收录的人群特异性插入事件。

### 结果

#### 来自多人群8,376例个体的高质量NUMTs

本研究最初分析了8,546例基因组，来源包括公共参考数据库（1000 Genomes Project、HGDP、SGDP）和本队列新招募样本。经质控过滤后（见方法部分），8,546例初始样本中8,376例（通过率98.01%）被纳入NUMT分析。质控流程评估了核DNA污染（VerifyBamID2）、线粒体DNA污染（Haplocheck）以及测序深度和覆盖度充分性，最终排除170例样本。

利用经认证的短读长NUMT检测流程（Wei等，2022），我们基于discordant read pairs——即一端比对至核基因组、另一端比对至线粒体基因组的测序read pairs——鉴定NUMT插入事件。候选NUMT事件在500 bp窗口内进行聚类，纳入标准要求≥5对discordant reads（严格阈值；宽松阈值为≥2对discordant reads）。跨样本在1,000 bp窗口内合并生成distinct NUMT clusters。

严格阈值数据集共鉴定111,487个distinct NUMT区域，分布于2,835个clusters。NUMT插入片段长度范围为24 bp至完整的线粒体基因组（16,568 bp），中位数为111 bp，均值为350.4 bp（图1a）。大多数NUMTs为短片段插入：63.2%小于200 bp，77.8%小于500 bp。

每位个体平均携带14.79个NUMTs（标准差 = 9.84），每样本范围为0至119个（图1b）。每样本NUMT计数分布近似正态分布，峰值集中在每样本约8个NUMTs附近，少数个体为高频携带者（>50个NUMTs）。NUMT事件分布于所有核染色体，但呈现非均匀模式，在1号染色体（17,519个事件）、2号染色体（17,039个）、11号染色体（10,869个）和17号染色体（9,716个）上富集，而在19号染色体（155个）和18号染色体（798个）上计数最低（图1c）。

NUMTs按群体频率分为四类：常见（频率≥0.05%）、低频（0.05% > F ≥ 0.01%）、稀有（0.01% > F ≥ 0.001%）和超稀有（F < 0.001%）。在2,835个distinct clusters中，超稀有NUMTs占主导地位（2,244个cluster，79.15%），其次为稀有（354个，12.49%）、低频（119个，4.20%）和常见（118个，4.16%）（图1d）。超稀有NUMTs的绝对优势反映了NUMT插入事件的持续发生以及负向选择对新整合序列的清除作用。

复发频率最高的NUMT cluster位于chr17:22519788–22531705，存在于9,822例样本中（频率99.99%），其次为chr1:629112–634816（80.90%）和chr11:49861727–49862240（68.98%）（补充表1）。这些超高频NUMTs几乎存在于所有个体中，提示它们代表了现代人类分化之前发生的古老插入事件，随后在人类群体中被固定或接近固定。

#### 新招募队列样本中的NUMT特征

仅限新招募队列样本的分析揭示了截然不同的NUMT谱。在相同的严格阈值（≥5对discordant reads）下，仅鉴定出1,236个distinct NUMT区域——约为全队列检出量的1.1%。NUMT长度明显更短，范围为29至533 bp，中位数为67 bp（全队列为111 bp），均值为74.6 bp（图2a）。值得注意的是，新样本中未检测到全mtDNA长度的NUMTs。

一个引人注目的发现是新样本中完全不存在常见NUMTs（F ≥ 0.05%）。在734个distinct clusters中，688个（93.73%）被归类为超稀有，而全队列中这一比例为79.15%（图2b）。其余clusters为稀有（38个，5.18%）和低频（8个，1.09%）。这一模式表明，仅在新招募队列中检出的NUMTs以样本特异性的超低频事件为主。

在每样本水平上，3,960例样本（47.28%）未检出可检测的NUMTs，而4,416例样本（52.72%）携带≥1个NUMT（图2c）。每样本均值为4.36个NUMTs（标准差 = 4.69），显著低于全队列平均值14.79。新样本中复发频率最高的NUMT clusters——chr17:22519788–22521650（52.72%）、chr1:629142–634816（41.51%）和chr11:49861766–49862240（40.38%））——的频率较全队列（分别为99.99%、80.90%和68.98%）显著降低，这可能反映了测序深度差异导致的检测灵敏度降低，而非真正的生物学缺失。

新样本中的染色体分布模式与全队列大体一致，NUMT事件富集于chr1（8,115个）、chr17（4,713个）、chr11（3,894个）和chr2（3,190个）（图2d）。然而，各染色体的事件计数显著降低，与NUMT检出量的整体下降成比例。

#### 排除已知参考NUMTs后的NUMT景观

为区分新发NUMT插入事件与参考数据库中已收录的事件，我们排除了所有与已知参考NUMTs重叠的cluster（UCSC NUMT track和已发表数据集；≥50%位置重叠）。排除后，全部8,376例样本中剩余17,181个distinct NUMT区域，占原始111,487个区域的15.4%（图3a）。

排除参考NUMTs后的中位长度为118 bp（均值334.7 bp），略高于未排除前的中位数111 bp，提示已知参考NUMTs中短片段插入的比例更高。排除参考后的NUMTs长度范围为29 bp至16,511 bp，表明即使是新发插入事件也可涵盖线粒体基因组的大片段。

Distinct cluster的分类结构与全队列分析保持一致：常见118个、低频119个、稀有354个、超稀有2,244个。然而，每样本NUMT计数分布受到影响：7,360例样本（87.87%）携带≥1个排除参考后的NUMT，而1,016例样本（12.13%）在排除后未检出可检测的NUMTs。这表明每样本NUMT负荷的主要部分由已知参考NUMTs贡献，仅有少数个体携带新发插入事件。

排除参考NUMTs后的染色体分布与全队列模式大体相似，事件计数最高的染色体依次为chr1（17,519个）、chr2（17,039个）、chr11（10,869个）和chr17（9,716个）。这些高计数染色体可能同时包含参考NUMTs和新发NUMTs，而事件计数的整体下降反映了已知插入事件的排除。

#### 新招募样本中队列特异性的新发NUMTs

最具生物学意义的分析聚焦于排除所有已知参考NUMTs后、仅在新招募队列样本中检出的新发NUMTs。该分析鉴定了1,102个distinct NUMT clusters，分布于1,604个总事件中，长度范围为29至533 bp（中位数67 bp，均值74.6 bp）（图4a）。

在1,098个distinct clusters中，频率分布严重偏向超稀有事件：966个cluster（87.98%）为超稀有，94个（8.56%）为稀有，22个（2.00%）为低频，值得注意的是，16个（1.46%）被归类为常见（F ≥ 0.05%）（图4b）。鉴定出16个队列特异性常见NUMTs——即在新样本中频率≥0.05%但在所有公共参考数据库中均未被记录的插入事件——是本研究的核心发现之一。这些NUMTs可能代表东亚人群特异性插入事件，通过遗传漂变或局部选择已达到可观的频率。

在每样本水平上，7,360例样本（87.87%）未携带新发NUMTs，仅1,016例样本（12.13%）携带≥1个新发插入（图4c）。每样本均值为0.19个NUMTs（标准差 = 1.09），范围为0至39。这一极低的负荷表明新发NUMT插入在个体水平极为罕见，约每8个个体中仅有1个携带至少一个此前未被收录的NUMT。

新发NUMT事件展现出与全队列不同的染色体分布模式。尽管chr1仍是事件最多的染色体（235个），chr13表现出最高的相对富集（375个事件，占总数的23.4%），其次为chr5（128个）和chr2（68个）（图4d）。chr13的异常高比例值得进一步研究，因为它可能反映了促进NUMT整合的局部序列特征（如LINE元件密度、染色质可及性）。

复发频率最高的新发NUMT clusters依次为：chr13:17231903–17232120（频率3.87%，324例样本）、chr11:4634854–4635460（3.64%，305例）和chr12:66057590–66057708（3.33%，279例）（补充表2）。它们均被归类为低频（0.05% > F ≥ 0.01%），最高频率（3.87%）显著低于参考NUMTs的频率（>40%），进一步证实了它们作为新近发生插入事件的地位。

### 讨论

本研究对8,376例质控合格多人群队列样本的NUMT频率分布进行了全面表征。我们的研究结果证实并扩展了既往大规模NUMT研究的观察，同时为线粒体-核DNA转移的人群特异性模式提供了新的见解。

超稀有NUMTs的绝对主导地位（占所有clusters的79.15%）与持续NUMT插入耦合新整合序列负向选择的模型一致。这一模式最初由Wei等（2022）在100,000 Genomes Project中描述，在本队列中得到了重现，提示NUMT插入和纯化选择的进化动力学在人类群体间是保守的。NUMT长度与群体频率之间的反向关系——常见NUMTs以短片段为主，而超稀有NUMTs涵盖更宽的尺寸范围（包括全基因组长度插入）——进一步支持了大片段NUMT插入具有有害性并受到纯化选择的假说。

本研究结果与100,000 Genomes Project发现的高度一致性值得关注。我们鉴定了2,835个distinct NUMT clusters，而Wei等（2022）报道为1,637个。本研究更高的cluster计数可能反映了队列中更广泛的人群多样性，其中新招募样本包含了大量东亚人群代表，同时纳入了多个参考数据库（1000 Genomes Project、HGDP、SGDP）， collectively捕获了更广泛的NUMT变异谱。

排除已知参考NUMTs后，15.4%的distinct NUMT区域（111,487个中的17,181个）被保留，表明本队列中约85%的NUMT事件与已收录的插入事件重叠。这种高度的重叠突显了人类NUMT景观的保守性，提示NUMT插入事件的主体框架已被现有数据库基本捕获。然而，剩余15%代表了大量新发插入事件，其中许多可能具有人群特异性。

在新招募队列样本中，鉴定出16个队列特异性常见NUMTs（新样本中F ≥ 0.05%但参考数据库中不存在）尤为引人关注。这些NUMTs频率范围为0.05%至3.87%，可能代表东亚人群特异性插入事件，通过遗传漂变或局部适应已达到可观的频率。chr13上复发频率最高的新发NUMT（chr13:17231903–17232120，频率3.87%，324例携带者）需要通过长读长测序进行结构验证及其基因组背景的功能评估。

仅12.13%的个体携带至少一个新发NUMT这一发现对我们理解持续的NUMT插入具有重要意义。这一比率与此前估计的约每10⁴次出生发生一次NUMT插入大致一致，提示线粒体-核DNA转移的速率在近期人类进化过程中保持相对恒定。然而，新发NUMTs在个体水平的极端稀有性意味着需要非常大的样本量才能捕获插入事件的全谱。

本研究的若干局限性应予说明。首先，短读长测序限制了我们解析复杂NUMT结构的能力，包括串联重复和串联NUMTs，这些结构在长读长验证研究中已被证明占插入事件的相当比例。其次，公共参考数据与新招募样本之间在测序平台和深度上的批次效应可能影响NUMT检出率的可比性。第三，用于排除的参考NUMT数据库主要基于欧洲裔人群，可能导致对东亚样本中"新发"NUMTs数量的高估。第四，本研究为描述性分析，未评估NUMT插入的功能后果，这需要与基因注释、表达和表观遗传数据整合分析。

未来研究应利用长读长测序技术验证高频新发NUMTs的结构并解析复杂的插入架构。将NUMT数据与临床表型整合可能揭示NUMT负荷与疾病易感性之间的关联。跨多样化人群的比较分析对于全面表征全球NUMT景观并理解塑造人类线粒体-核DNA转移的进化力量至关重要。

### 材料与方法

#### 研究人群与样本

本研究共分析了8,546例全基因组测序样本，来源包括多个数据库：公共参考数据库涵盖1000 Genomes Project（1KGP）、Human Genome Diversity Project（HGDP）和Simons Genome Diversity Project（SGDP）；新招募队列样本来自本研究队列（具体队列名称、样本量和招募细节待补充）。

所有样本均经统一质控流程处理。质控评估包括核DNA污染估算（VerifyBamID2）、线粒体DNA污染评估（Haplocheck）以及测序深度和覆盖度检查。质控后，8,546例初始样本中8,376例（98.01%）被纳入NUMT分析，170例被排除。

#### 测序与比对

全基因组测序采用Illumina短读长技术（具体平台和read长度细节待补充）。Reads使用BWA-mem比对至GRCh38参考基因组，包含修订版剑桥参考序列（rCRS, NC_012920.1）作为线粒体基因组。

#### NUMT检测流程

NUMT检测遵循Wei等（2022）描述的经认证短读长流程。首先，samblaster从比对后的BAM文件中提取discordant read pairs，定义为一端比对至核基因组、另一端比对至线粒体基因组的read pairs。其次，将500 bp窗口内的discordant reads基于其核基因组坐标聚类为候选NUMT事件。第三，应用两个严格度水平进行阈值过滤：严格阈值要求每个候选NUMT由≥5对discordant reads支持（主要分析），宽松阈值要求≥2对discordant reads（探索性分析）。第四，将不同样本中1,000 bp窗口内的NUMT事件合并为distinct NUMT clusters，cluster中点定义为所有组成事件中点的均值。第五，NUMT clusters按其在队列中的携带频率进行分类：常见（频率≥0.05%）、低频（0.05% > 频率≥0.01%）、稀有（0.01% > 频率≥0.001%）和超稀有（频率<0.001%）。第六，将检测到的NUMT clusters与已知参考NUMT数据库（UCSC NUMT track和已发表数据集）进行比对，与参考NUMTs位置重叠≥50%的cluster被排除于新发NUMT分析之外。

#### 统计分析

NUMT长度分布采用描述性统计（最小值、最大值、均值、中位数、标准差）进行汇总。每样本NUMT计数计算为与每个个体discordant read pairs重叠的distinct NUMT区域数量。染色体NUMT事件计数在全部24条染色体（chr1至chr22、chrX、chrY）上进行统计。所有分析均使用自定义R和Python脚本完成。

#### 软件与计算环境

比对采用BWA-mem（具体版本待补充），discordant reads提取采用samblaster，NUMT聚类和分析采用自定义流程（具体版本和代码仓库待补充），统计分析使用R和Python（版本待补充），参考基因组为GRCh38配合rCRS mtDNA（NC_012920.1），质控工具包括VerifyBamID2和Haplocheck。

#### 数据可用性

### Abstract

**Background:** Nuclear mitochondrial DNA segments (NUMTs) represent fragments of mitochondrial DNA that have integrated into the nuclear genome throughout evolutionary history. While recent large-scale studies have begun to catalogue the human NUMT landscape, population-specific patterns — particularly in East Asian populations — remain incompletely characterized.

**Methods:** We applied a validated short-read NUMT detection pipeline requiring at least five discordant read pairs to whole-genome sequencing data from 8,376 quality-controlled samples, encompassing public reference populations (1000 Genomes Project, HGDP, SGDP) and newly recruited cohort samples. NUMTs were classified by population frequency into common (at least 0.05%), low-frequency (0.05% to 0.01%), rare (0.01% to 0.001%), and ultra-rare (below 0.001%) categories. Known reference NUMTs were excluded to identify novel insertion events.

**Results:** We identified 111,487 distinct NUMT regions across 2,835 clusters. Ultra-rare NUMTs predominated (79.15%), consistent with ongoing insertion and negative selection. Each individual carried a mean of 14.79 NUMTs (standard deviation = 9.84). After excluding known reference NUMTs, 17,181 distinct regions (15.4% of total) remained, of which 16 represented cohort-specific common insertions not previously catalogued. Newly recruited cohort samples showed a markedly higher proportion of ultra-rare NUMTs (93.73% versus 79.15% in the full cohort) and a lower per-sample NUMT burden (mean 4.36 versus 14.79), with 47.28% of samples carrying no detectable NUMTs under the strict threshold. The most recurrent NUMT (chr17:22519788–22531705) was present in 99.99% of individuals. NUMT length exhibited an inverse relationship with population frequency (median 111 bp for common versus 67 bp for novel events). Chromosomal distribution was non-random, with enrichment on chromosomes 1, 2, 11, and 17.

**Conclusions:** This study provides a comprehensive characterization of NUMT frequency distribution in a multi-population cohort, confirming the high conservation of the human NUMT landscape while identifying population-specific insertion events. These findings establish a reference resource for future studies investigating the functional and clinical implications of NUMTs.

### Introduction

Mitochondrial DNA transfer to the nuclear genome is an ongoing evolutionary process that has shaped eukaryotic genomes for hundreds of millions of years. Nuclear mitochondrial DNA segments (NUMTs) — fragments of mtDNA integrated into nuclear chromosomes — are ubiquitous across eukaryotic species and serve as molecular fossils recording the history of intergenomic DNA transfer. In humans, NUMTs range from short insertions of a few base pairs to nearly the entire mitochondrial genome (16,569 bp), and their accumulation rate has been estimated at approximately one insertion per 10,000 births.

The study of NUMTs has gained renewed interest for several reasons. First, NUMTs represent a source of genomic variation with potential functional consequences, including gene disruption, altered gene expression, and genomic instability. NUMT insertions have been implicated in several human diseases, including mucolipidosis type IV, Pallister-Hall syndrome, and various cancers. Second, NUMTs can confound mitochondrial genomic analyses by generating false heteroplasmy calls in next-generation sequencing data, making their accurate characterization essential for mitochondrial genome studies. Third, the non-random distribution of NUMTs across the nuclear genome provides insights into the mechanisms of DNA repair and retrotransposition that mediate mitochondrial-to-nuclear DNA transfer.

Recent large-scale studies have begun to systematically catalogue NUMTs in human populations. Wei and colleagues (2022) analysed whole-genome sequencing data from the 100,000 Genomes Project, identifying 254,195 NUMT events (1,637 distinct NUMTs) at a detection threshold of at least five discordant read pairs. They demonstrated that NUMTs are non-randomly distributed across the nuclear genome, exhibit an inverse relationship between insertion length and population frequency, and show ethnic group-specific patterns. However, these studies have been predominantly based on European-ancestry populations, leaving the NUMT landscape in East Asian and other underrepresented populations incompletely characterized.

Here, we present a comprehensive analysis of NUMT frequency distribution in a multi-population cohort of 8,376 quality-controlled samples, combining public reference data (1000 Genomes Project, Human Genome Diversity Project, Simons Genome Diversity Project) with newly recruited cohort samples. Using a validated short-read NUMT detection pipeline, we characterize the NUMT landscape across frequency categories, compare patterns between reference and novel samples, and identify population-specific insertion events not previously catalogued.

### Results

#### High-quality NUMTs from 8,376 individuals across multiple populations

We initially studied 8,546 genomes from multiple sources, including public reference databases (1000 Genomes Project, HGDP, SGDP) and newly recruited cohort samples. After quality control filtering (see Methods), 8,376 of 8,546 initial samples (pass rate 98.01%) were retained for NUMT analysis. The quality control pipeline assessed nuclear DNA contamination (VerifyBamID2), mitochondrial DNA contamination (Haplocheck), and sequencing depth and coverage adequacy, resulting in the exclusion of 170 samples.

Using a validated short-read NUMT detection pipeline (Wei et al., 2022), we identified NUMT insertions based on discordant read pairs — sequencing read pairs in which one end maps to the nuclear genome and the other to the mitochondrial genome. Candidate NUMT events were clustered within 500 bp windows and required at least five discordant read pairs for inclusion under the strict threshold, or at least two under the relaxed threshold. Cross-sample merging within 1,000 bp windows yielded distinct NUMT clusters.

The strict-threshold dataset identified 111,487 distinct NUMT regions distributed across 2,835 clusters. NUMT insertion lengths ranged from 24 bp to the full mitochondrial genome (16,568 bp), with a median of 111 bp and a mean of 350.4 bp (Fig. 1a). The majority of NUMTs were short insertions: 63.2% were less than 200 bp and 77.8% were less than 500 bp in size.

Individuals carried an average of 14.79 NUMTs (standard deviation = 9.84), ranging from 0 to 119 per sample (Fig. 1b). The per-sample NUMT count distribution approximated a normal distribution centred near 8 NUMTs per sample, with a minority of high carriers exceeding 50 NUMTs. NUMT events were distributed across all nuclear chromosomes but exhibited a non-uniform pattern, with enrichment on chromosome 1 (17,519 events), chromosome 2 (17,039), chromosome 11 (10,869), and chromosome 17 (9,716), and the lowest counts on chromosome 19 (155) and chromosome 18 (798) (Fig. 1c).

NUMTs were classified by population frequency into four categories: common (frequency at least 0.05%), low-frequency (0.05% to 0.01%), rare (0.01% to 0.001%), and ultra-rare (below 0.001%). Among 2,835 distinct clusters, ultra-rare NUMTs predominated (2,244 clusters, 79.15%), followed by rare (354, 12.49%), low-frequency (119, 4.20%), and common (118, 4.16%) categories (Fig. 1d). The overwhelming predominance of ultra-rare NUMTs reflects the ongoing occurrence of NUMT insertion events and the action of negative selection against newly integrated sequences.

The most recurrent NUMT cluster was located at chr17:22519788–22531705, present in 9,822 samples (99.99% frequency), followed by chr1:629112–634816 (80.90%) and chr11:49861727–49862240 (68.98%) (Supplementary Table 1). These ultra-high-frequency NUMTs are present in nearly all individuals, suggesting they represent ancient insertion events that occurred before modern human diversification and have been subsequently fixed or nearly fixed in the human population.

#### NUMT characteristics in newly recruited cohort samples

Analysis restricted to the newly recruited cohort samples revealed a distinct NUMT profile. Under the same strict threshold of at least five discordant read pairs, only 1,236 distinct NUMT regions were identified — approximately 1.1% of the yield from the full cohort. NUMT lengths were notably shorter, ranging from 29 to 533 bp with a median of 67 bp compared to 111 bp in the full cohort, and a mean of 74.6 bp (Fig. 2a). Notably, no full-mtDNA-length NUMTs were detected in the new sample set.

A striking finding was the complete absence of common NUMTs in the new samples. Among 734 distinct clusters, 688 (93.73%) were classified as ultra-rare, compared to 79.15% in the full cohort (Fig. 2b). The remaining clusters were rare (38, 5.18%) and low-frequency (8, 1.09%). This pattern indicates that NUMTs detected exclusively in the newly recruited cohort are predominantly sample-specific, ultra-low-frequency events.

At the per-sample level, 3,960 samples (47.28%) carried no detectable NUMTs, while 4,416 samples (52.72%) harboured at least one NUMT (Fig. 2c). The per-sample mean was 4.36 NUMTs (standard deviation = 4.69), substantially lower than the full-cohort average of 14.79. The most recurrent NUMT clusters in new samples — chr17:22519788–22521650 (52.72%), chr1:629142–634816 (41.51%), and chr11:49861766–49862240 (40.38%) — showed markedly reduced frequencies compared to the full cohort (99.99%, 80.90%, and 68.98%, respectively), likely reflecting reduced detection sensitivity due to sequencing depth differences rather than true biological absence.

The chromosomal distribution pattern in new samples was broadly consistent with the full cohort, with NUMT events enriched on chromosome 1 (8,115), chromosome 17 (4,713), chromosome 11 (3,894), and chromosome 2 (3,190) (Fig. 2d). However, event counts on each chromosome were substantially lower, proportional to the overall reduction in NUMT detection.

#### NUMT landscape after excluding known reference NUMTs

To distinguish novel NUMT insertion events from those already catalogued in reference databases, we excluded all NUMT clusters overlapping with known reference NUMTs from the UCSC NUMT track and published datasets, requiring at least 50% positional overlap. After exclusion, 17,181 distinct NUMT regions remained across all 8,376 samples, representing 15.4% of the original yield of 111,487 regions (Fig. 3a).

The median length of reference-excluded NUMTs was 118 bp (mean 334.7 bp), slightly higher than the unexcluded median of 111 bp, suggesting that known reference NUMTs include a higher proportion of short-fragment insertions. The range of reference-excluded NUMTs spanned 29 bp to 16,511 bp, indicating that even novel insertions can encompass large segments of the mitochondrial genome.

The distinct cluster classification structure remained consistent with the full analysis: 118 common, 119 low-frequency, 354 rare, and 2,244 ultra-rare clusters. However, the per-sample NUMT count distribution was affected: 7,360 samples (87.87%) carried at least one reference-excluded NUMT, while 1,016 samples (12.13%) had no detectable NUMTs after exclusion. This indicates that the majority of per-sample NUMT burden is attributable to known reference NUMTs, with a minority of individuals carrying novel insertion events.

The chromosomal distribution of reference-excluded NUMTs was broadly similar to the full-cohort pattern, with the highest event counts on chromosome 1 (17,519), chromosome 2 (17,039), chromosome 11 (10,869), and chromosome 17 (9,716). These high-count chromosomes are likely to harbour both reference and novel NUMTs, while the overall reduction in event count reflects the exclusion of known insertions.

#### Cohort-specific novel NUMTs in newly recruited samples

The most biologically informative analysis focused on novel NUMTs detected exclusively in the newly recruited cohort samples after excluding all known reference NUMTs. This analysis identified 1,102 distinct NUMT clusters distributed across 1,604 total events, with lengths ranging from 29 to 533 bp (median 67 bp, mean 74.6 bp) (Fig. 4a).

Among 1,098 distinct clusters, the frequency distribution was heavily skewed toward ultra-rare events: 966 clusters (87.98%) were ultra-rare, 94 (8.56%) were rare, 22 (2.00%) were low-frequency, and notably, 16 (1.46%) were classified as common, defined as a frequency of at least 0.05% (Fig. 4b). The identification of 16 cohort-specific common NUMTs — insertion events occurring at frequencies of at least 0.05% in the new samples but absent from all public reference databases — represents one of the key findings of this study. These NUMTs may represent East Asian population-specific insertions that have reached appreciable frequencies through genetic drift or local adaptation.

At the per-sample level, 7,360 samples (87.87%) carried no novel NUMTs, while only 1,016 samples (12.13%) harboured at least one novel insertion (Fig. 4c). The per-sample mean was 0.19 NUMTs (standard deviation = 1.09), with a range of 0 to 39. This extremely low burden indicates that novel NUMT insertions are exceedingly rare at the individual level, with approximately one in eight individuals carrying at least one previously uncatalogued NUMT.

Novel NUMT events showed a distinct chromosomal distribution compared to the full cohort. While chromosome 1 remained the most frequently targeted chromosome with 235 events, chromosome 13 exhibited the highest relative enrichment with 375 events (23.4% of total), followed by chromosome 5 (128 events) and chromosome 2 (68 events) (Fig. 4d). The disproportionate representation of chromosome 13 warrants further investigation, as it may reflect local sequence features such as LINE element density or chromatin accessibility that favour NUMT integration.

The most recurrent novel NUMT clusters were located at chr13:17231903–17232120 (frequency 3.87%, 324 samples), chr11:4634854–4635460 (3.64%, 305 samples), and chr12:66057590–66057708 (3.33%, 279 samples) (Supplementary Table 2). All were classified as low-frequency, with the highest frequency of 3.87% substantially below that of reference NUMTs exceeding 40%, confirming their status as recently occurred insertion events.

### Discussion

This study presents a comprehensive characterization of NUMT frequency distribution in a multi-population cohort of 8,376 quality-controlled samples. Our findings confirm and extend the observations of previous large-scale NUMT studies, while providing new insights into population-specific patterns of mitochondrial-to-nuclear DNA transfer.

The overwhelming predominance of ultra-rare NUMTs, accounting for 79.15% of all clusters, is consistent with a model of ongoing NUMT insertion coupled with negative selection against newly integrated sequences. This pattern, first described by Wei and colleagues (2022) in the 100,000 Genomes Project, is recapitulated in our cohort, suggesting that the evolutionary dynamics of NUMT insertion and purifying selection are conserved across human populations. The inverse relationship between NUMT length and population frequency — with common NUMTs being predominantly short fragments and ultra-rare NUMTs spanning a wider size range including full-genome-length insertions — further supports the hypothesis that large NUMT insertions are deleterious and subject to purifying selection.

The high concordance between our findings and those of the 100,000 Genomes Project is noteworthy. We identified 2,835 distinct NUMT clusters compared to 1,637 reported by Wei and colleagues (2022). The higher cluster count in our study likely reflects the broader population diversity in our cohort, which includes substantial East Asian representation through the newly recruited samples, as well as the inclusion of multiple reference databases that collectively capture a wider spectrum of NUMT variation.

After excluding known reference NUMTs, 15.4% of distinct NUMT regions remained, representing 17,181 out of 111,487, indicating that approximately 85% of NUMT events in our cohort overlap with previously catalogued insertions. This high degree of overlap underscores the conservation of the human NUMT landscape and suggests that the major framework of NUMT insertions has been largely captured by existing databases. However, the remaining 15% represents a substantial number of novel insertion events, many of which may be population-specific.

Among the newly recruited cohort samples, the identification of 16 cohort-specific common NUMTs is particularly intriguing. These NUMTs, with frequencies ranging from 0.05% to 3.87%, may represent East Asian population-specific insertions that have reached appreciable frequencies through genetic drift or local adaptation. The most recurrent novel NUMT on chromosome 13, located at chr13:17231903–17232120 with a frequency of 3.87% and 324 carriers, warrants structural validation through long-read sequencing and functional assessment of its genomic context.

The finding that only 12.13% of individuals carry at least one novel NUMT has important implications for our understanding of ongoing NUMT insertion. This rate is broadly consistent with previous estimates of approximately one NUMT insertion per 10,000 births, suggesting that the rate of mitochondrial-to-nuclear DNA transfer has remained relatively constant throughout recent human evolution. However, the extreme rarity of novel NUMTs at the individual level means that very large sample sizes are required to capture the full spectrum of insertion events.

Several limitations of this study should be acknowledged. First, the use of short-read sequencing limits our ability to resolve complex NUMT structures, including tandem duplications and concatenated NUMTs, which have been shown to comprise a significant proportion of insertion events in long-read validation studies. Second, batch effects between public reference data and newly recruited samples in terms of sequencing platform and depth may affect the comparability of NUMT detection rates. Third, the reference NUMT databases used for exclusion are predominantly based on European-ancestry populations, potentially leading to overestimation of novel NUMTs in East Asian samples. Fourth, this study is descriptive in nature and does not assess the functional consequences of NUMT insertions, which will require integration with gene annotation, expression, and epigenetic data.

Future studies should leverage long-read sequencing technologies to validate the structure of high-frequency novel NUMTs and resolve complex insertion architectures. Integration of NUMT data with clinical phenotypes may reveal associations between NUMT burden and disease susceptibility. Comparative analyses across diverse populations will be essential to fully characterize the global NUMT landscape and understand the evolutionary forces shaping mitochondrial-to-nuclear DNA transfer in humans.

### Materials and Methods

#### Study Population and Samples

A total of 8,546 whole-genome sequenced samples were analysed, sourced from multiple databases. Public reference databases included the 1000 Genomes Project, the Human Genome Diversity Project, and the Simons Genome Diversity Project. Newly recruited cohort samples were drawn from the current study cohort, with specific cohort name, sample size, and recruitment details to be provided.

All samples were processed through a unified quality control pipeline. Quality control assessments included nuclear DNA contamination estimation using VerifyBamID2, mitochondrial DNA contamination evaluation using Haplocheck, and sequencing depth and coverage checks. After quality control, 8,376 of the initial 8,546 samples (98.01%) were retained for NUMT analysis, with 170 samples excluded.

#### Sequencing and Alignment

Whole-genome sequencing was performed using Illumina short-read technology, with specific platform and read length details to be provided. Reads were aligned to the GRCh38 reference genome, including the revised Cambridge Reference Sequence (rCRS, NC_012920.1) for the mitochondrial genome, using BWA-mem.

#### NUMT Detection Pipeline

NUMT detection followed the validated short-read pipeline described by Wei and colleagues (2022). Discordant read pairs were extracted from aligned BAM files using samblaster, defined as pairs where one read maps to the nuclear genome and the other to the mitochondrial genome. Discordant reads within 500 bp windows were clustered into candidate NUMT events based on their nuclear genomic coordinates. Two stringency levels were applied for threshold filtering: the strict threshold required at least five discordant read pairs supporting each candidate NUMT and served as the primary analysis, while the relaxed threshold required at least two discordant read pairs for exploratory analysis. NUMT events across different samples within 1,000 bp windows were merged into distinct NUMT clusters, with the cluster midpoint defined as the mean of all constituent event midpoints. NUMT clusters were classified by their carrier frequency in the cohort into four categories: common at frequencies of at least 0.05%, low-frequency between 0.05% and 0.01%, rare between 0.01% and 0.001%, and ultra-rare below 0.001%. Detected NUMT clusters were compared against known reference NUMT databases from the UCSC NUMT track and published datasets, and clusters with at least 50% positional overlap with reference NUMTs were excluded from the novel NUMT analysis.

#### Statistical Analysis

NUMT length distributions were summarized using descriptive statistics including minimum, maximum, mean, median, and standard deviation. Per-sample NUMT counts were calculated as the number of distinct NUMT regions overlapping each individual's discordant read pairs. Chromosomal NUMT event counts were tallied across all 24 chromosomes, comprising chromosomes 1 through 22 plus the X and Y chromosomes. All analyses were performed using custom R and Python scripts.

#### Software and Computational Environment

Alignment was performed using BWA-mem, with the specific version to be provided. Discordant read extraction was performed using samblaster. NUMT clustering and analysis were conducted using a custom pipeline, with the specific version and code repository to be provided. Statistical analysis was performed using R and Python, with versions to be provided. The reference genome was GRCh38 with rCRS mtDNA (NC_012920.1). Quality control tools included VerifyBamID2 and Haplocheck.

NUMT detection results and summary statistics are available at locations to be specified in the final data availability statement.
