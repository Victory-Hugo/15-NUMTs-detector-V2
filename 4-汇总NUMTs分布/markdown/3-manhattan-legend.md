# Figure legend | 图注

**English**

Figure X. Genome-wide Manhattan plots of NUMTs clusters. Points represent clustered NUMTs breakpoints mapped to genome-wide coordinates (x axis). Colors denote chromosomes ordered from chr1–chr22, chrX, and chrY. (A) Cluster size plot: the y axis shows the number of unique breakpoint positions per cluster (POS). (B) Sample recurrence plot: the y axis shows the number of samples sharing each cluster (sample_count). The plots highlight a small number of highly recurrent hotspots against a background of mostly singleton clusters.

**中文**

图X. NUMTs 聚类的全基因组 Manhattan 图。点表示聚类后的 NUMTs 断点位置，x 轴为全基因组拼接坐标，颜色按 chr1–chr22、chrX、chrY 顺序表示不同染色体。(A) 聚类规模图：y 轴为每个聚类包含的独立断点位置数（POS）。(B) 样本复现度图：y 轴为共享该聚类的样本数（sample_count）。结果显示少数高复现热点与大量单例聚类共存。
