# 新旧版本 NUMTs 检测脚本对比总结

**对比对象**
- 旧版原始脚本：`NUMTs-detection-master/scripts/`
- 新版重构脚本：`15-NUMTs-detector-V2/1-1-获得NUMTs分布旧版/python/`

---

## 核心结论

**所有生物学判别阈值均未修改。** 新版仅做了工程层面的重构（Python 3 兼容、命名参数、日志、错误处理），以及修复了两处旧版的功能性缺陷。

## 新版修复的两处功能性缺陷（不影响阈值）

### 1. Tname 归一化（searchBreakpoint）

旧版直接用 `Tname.isin(['chrM','MT'])` 识别线粒体 reads。若 BLAT 比对所用参考基因组采用 RefSeq accession 命名（如 `NC_012920.1`），旧版会将所有 MT reads 漏判，导致该样本断点输出为空。

新版增加 `normalize_target_name()` 函数，将 `NC_012920.1` → `chrM`、`NC_000001.11` → `chr1` 等 accession 映射为标准名称后再过滤。**判别逻辑和阈值本身未变，仅扩展了输入兼容性。**

### 2. breakpointINPUT.tsv 读取方式（groupNumtCluster）

旧版以默认 `header=0` 读取无表头的 TSV 文件，导致第一行数据被当作列名，后续 `drop_duplicates(["sampleID","chr","start"])` 会因列名不存在而报错或丢失第一条记录。新版明确指定 `header=None`，正确读取。**聚类逻辑和 maxgap 参数未变。**

## 流程结构变化（与判别阈值无关）

- 新版 `run_pipeline.sh` 增加了多样本汇总步骤（调用 `groupNumtCluster`），旧版 `NUMTs_detection.sh` 无此步骤，属于功能扩展。
- 新版每个样本输出至独立子目录，旧版平铺至同一目录，属于工程改动。
- Python 脚本由位置参数改为命名参数，属于接口改动。
