# 结果解读
得到的关键文件是 `5-富集/output/enrichment_summary.tsv`。

1. 先有一个“观测值”：脚本里观测值是：
```sh
Observed_Percentage = NUMTS_TARGET / NUMTS_TOTAL
```
也就是“真实数据中，NUMTs 落在目标区域的比例”。

2. 再做很多次随机模拟：每次模拟：随机放置 NUMTs，算一个“随机比例”。
于是会得到一堆随机比例，形成一个分布。

3. P_value_less 是什么
脚本算的是：
```sh
P_value_less = 1 - (随机比例 > 观测比例 的比例)
```

这等价于：随机比例 ≤ 观测比例 的概率。
也就是：随机情况下“比你更少”的概率。

>[!question] 如何判断显著少？
如果 P_value_less 很小（<0.05），说明
“随机情况下几乎不会比你更少”
→ 你的观测值已经非常小
→ 目标区域中的 NUMTs 显著少于随机。

P_value_greater 类似
它是“随机比例 ≥ 观测比例”的概率（脚本换了写法但等价）。
若它很小，说明观测值非常大 → 显著多于随机。

所以判断规则是：
```sh
P_value_less < 0.05 → 显著少于随机
P_value_greater < 0.05 → 显著多于随机
两者都不小 → 无显著差异
```
举个例子：
在你的结果里：
```sh
P_value_less = 0.0005 很小，P_value_greater = 1 不小
→ 结论是“显著少于随机”。
```

```sh
情况                               结果解释
P_value_less < 0.05 且 P_value_greater ≥ 0.05   目标区域中 NUMTs 显著少于随机（去富集）
P_value_greater < 0.05 且 P_value_less ≥ 0.05   目标区域中 NUMTs 显著多于随机（富集）
P_value_less ≥ 0.05 且 P_value_greater ≥ 0.05   与随机分布无显著差异
P_value_less < 0.05 且 P_value_greater < 0.05   理论上不常见，可能是模拟/计算问题或阈值设置问题
```
