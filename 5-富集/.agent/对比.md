# NUMT断点侧翼富集分析：文献方法与脚本实现对比

## 一、文献方法描述

依据女娲基因组论文（bioRxiv, 2025）方法部分第649-660行：

> Resampling 10,000 sets of random nuclear positions in 200 bp NUMT flanks (upstream 100 bp + downstream 100 bp) based on total number of NUMTs (permutation test) was performed to generate empirical P values by comparing with the observed NUMTs in target regions.

**方法要点**：
- 对每个NUMT断点定义200bp侧翼窗口（断点上游100bp + 下游100bp）
- 基于断点总数进行10,000次随机重采样
- 通过置换检验（permutation test）计算经验P值

## 三、核心算法验证

### 3.1 断点侧翼区域提取

**文件**：`prepare_breakpoint_flanks.py`（第179-198行）

**处理逻辑**：
1. 按 `merged_cluster_id` + `Group`（nuleft/nuright）组合去重，确保每个NUMT事件的左右断点各保留一个代表性位置
2. 对每个断点位置定义侧翼区域：`[pos - 100bp, pos + 100bp]`
3. 输出BED格式文件供后续富集分析使用

### 3.2 置换检验实现

**文件**：`run_one_breakpoint_enrichment.py`（第115-145行）

```python
# 侧翼窗口长度
flank_length = int(flank_bp) * 2  # = 200bp

# 无放回随机采样（与文献方法一致）
random_start = rng.choice(max_start, size=breakpoints_total, replace=False) + 1
random_end = random_start + flank_length  # 固定200bp窗口

# 经验P值计算（双尾检验）
p_value_less = (detail_df["percentage"] <= observed_percentage).mean()
p_value_greater = (detail_df["percentage"] >= observed_percentage).mean()
```

**关键实现细节**：
- 使用伪参考坐标（pseudo-reference）将多染色体坐标映射到连续空间，避免染色体边界问题
- 目标区域区间合并后进行向量化重叠检测，提升计算效率
- 采用确定性随机种子派生机制，保证结果可重复性

## 四、结论

**脚本实现与文献方法完全一致**，具体体现在：

1. **窗口定义**：采用固定200bp滑动窗口（断点上游100bp + 下游100bp）
2. **模拟规模**：执行10,000次迭代模拟
3. **采样策略**：无放回随机采样（`replace=False`），避免同一位置重复采样
4. **统计推断**：基于断点总数计算经验P值，支持双向显著性检验
5. **基因组范围**：覆盖GRCh38全部常染色体（chr1-22）及性染色体（X、Y）

> **注意**：文献中明确使用的是**断点侧翼区域**（breakpoint flanks）而非NUMT插入区域本身进行富集分析，脚本实现了这一核心逻辑。
