# 富集分析输入文件选择说明

## 当前结论

当前 `5-富集` 已切换为与论文 Figure 7D 对齐的 **NUMT nuclear breakpoint ±100 bp flank enrichment**。因此，位置主输入不再是 `4-numt-frequency-by-cluster.tsv` 派生出的 distinct NUMT 插入区间，而是 QC 后的 confident nuclear breakpoint 表。

主流程需要以下输入：

```text
/mnt/l/20-NUMTs/6-NUMTs频率分布描述/2-严格阈值-v2/output/01-qc/2-confident_breakpoints.pass.tsv.gz
/mnt/l/20-NUMTs/6-NUMTs频率分布描述/2-严格阈值-v2/output/01-qc/4-mt_disc_breakpoint_input.pass.tsv.gz
/mnt/l/20-NUMTs/6-NUMTs频率分布描述/2-严格阈值-v2/output/02-tables/4-mt_disc_breakpoint_input.min-support-1.allCluster.tsv
/mnt/l/20-NUMTs/6-NUMTs频率分布描述/2-严格阈值-v2/output/02-tables/4-numt-frequency-by-cluster.tsv
```

其中：

| 文件 | 当前用途 |
|---|---|
| `2-confident_breakpoints.pass.tsv.gz` | 提供 confident nuclear breakpoints，筛选 `nuleft/nuright` 后构造上下游各 100 bp flank |
| `4-mt_disc_breakpoint_input.pass.tsv.gz` | 提供样本级 NUMT 事件坐标，用于把 breakpoint 追溯回聚类事件 |
| `4-mt_disc_breakpoint_input.min-support-1.allCluster.tsv` | 提供 cross-sample cluster 映射，用于关联 `mergedClusterID` |
| `4-numt-frequency-by-cluster.tsv` | 提供 `frequency_class`，用于 `common/low-frequency/rare/ultra-rare` 分层 |

## 与旧方法的区别

旧版 `5-富集` 用 `4-numt-frequency-by-cluster.tsv` 构造 distinct NUMT interval：

```text
bed_start = cluster_min_midpoint - chosen_region_length / 2
bed_end   = cluster_max_midpoint + chosen_region_length / 2
```

这回答的是“distinct NUMT 插入区间更常与哪些区域重叠”。

当前版本改为：

```text
breakpoint_start = nuclear_breakpoint_pos - 100
breakpoint_end   = nuclear_breakpoint_pos + 100
```

这回答的是“NUMT 核基因组断点附近 200 bp 窗口更常出现在什么 genomic feature 中”，更接近论文 Figure 7D 的统计定义。

## 为什么仍然保留 `4-numt-frequency-by-cluster.tsv`

用户要求分层仍使用本项目更细的分类：

```text
all
common
low-frequency
rare
ultra-rare
```

因此 `4-numt-frequency-by-cluster.tsv` 仍然是必要输入，但它现在只负责给断点 flank 赋予频率层级，不再负责提供富集分析的核基因组 interval 坐标。

## 不建议作为当前主流程位置输入的文件

### `7-mt_disc_cluster.tsv.gz`

这是原始候选 NUMT 区域表，不是 QC 后的 confident nuclear breakpoint 表，也不是 Figure 7D 的 flank 输入。

### `4-numt-frequency-by-cluster.tsv`

这是 distinct cluster 频率表，适合作为分层依据；但若直接从它构造 NUMT interval，会回到旧的 interval-overlap 问题，不再严格对齐 Figure 7D 的 breakpoint flank enrichment。

### `8-merge_bed.tsv.gz` / `9-merge_bed_confident.tsv.gz`

这些更偏 mtDNA hit/长度相关信息，不适合作为核基因组区域富集的主位置输入。

## 当前目标 BED

主流程默认扫描：

```text
data/regions/*.bed
```

该目录由一次性资源脚本生成，不接入主流程：

```bash
bash script/prepare_article_regions_bed.sh \
  --output-dir data/regions \
  --source-dir data/source/article_regions \
  --tmp-dir data/tmp/article_regions \
  --raw-dir data/raw \
  --bedtools-bin bedtools
```
