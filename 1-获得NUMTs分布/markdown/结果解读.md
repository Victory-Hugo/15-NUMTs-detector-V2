## 1. 文件生成流程图

```ascii
输入：BAM文件 (HG001.bam)
    |
    v

│                                                             │
│ samtools view + grep + samblaster                           │

│    └── HG001.mt.split.sam      (分裂读)                     │

    |
    v
┌─────────────────────────────────────────────────────────────┐

│                                                             │

│    ├── HG001.mt.disc.sam.breakpointINPUT.tsv               │
│    ├── HG001.mt.disc.sam.cluster.tsv                       │
│    ├── HG001.mt.disc.sam.cluster.old.tsv                   │
│    └── HG001.mt.disc.sam.cluster.summary.tsv               │

    |
    v
```

## 2. 输出文件说明

### 2.1 聚类阶段文件

#### `*.breakpointINPUT.tsv` - 聚类输入文件
每行代表一个候选NUMT区域，供后续断点分析使用。

**列含义：**
```
列1: sampleID           样本ID (如：HG001)
列2: cluster_no         聚类编号 (如：3)
列3: disFile           disc SAM文件路径
列4: splitFile         split SAM文件路径  
列5: wgsBAM            原始BAM文件路径
列6: chr               染色体名称 (如：chr1)
列7: start             候选区域起始位置 (如：633396)
列8: end               候选区域结束位置 (如：634413)
```

**示例：**
```
HG001	3	/path/to/HG001.mt.disc.sam	/path/to/HG001.mt.split.sam	/path/to/HG001.bam	chr1	633396	634413
```

#### `*.cluster.tsv` - 详细聚类结果
每行代表一个聚类区域的详细信息。

**列含义：**
```
列1: chr                染色体名称
列2: start              聚类区域起始位置
列3: end                聚类区域结束位置
列4: Cluster_No         聚类编号
列5: reads              该聚类中的reads位置列表
列6: mt_positions       对应的线粒体位置列表
列7: subCluster_No      子聚类编号
列8: Cluster_ID         聚类标识符
列9: IndividualID       样本个体ID
```

**示例：**
```
chr1	633396	634413	3	[633896, 633900, 633913]	[9735, 9872, 9818]	3	chr1_633896_633913_chrMboth_9735_9872	HG001
```

#### `*.cluster.summary.tsv` - 聚类汇总统计
每行汇总一个聚类的基本统计信息。

**列含义：**
```
列1: index              索引号
列2: IndividualID       样本个体ID
列3: Cluster_ID         聚类标识符
列4: totalReads         总reads数
列5: uniqueReads        唯一reads数
列6: clusterCount       聚类数量
```

**示例：**
```
0	HG001	chr11_49861875_49862357_chrMboth_16089_16340	2	2	1
```

### 2.2 比对阶段文件

#### `*_all_regions.fasta` - 合并序列文件
包含所有候选区域的reads序列，header格式为：`PREFIX|readID`

**格式：**
```
>HG001_chr1.633396.634413|HWI-D00360:5:H814YADXX:2:1208:19606:98914
ATCGATCGATC...
```

#### `*_all_regions.bwa.sam` - BWA比对结果
标准SAM格式的比对结果文件。

#### `*_all_regions.psl` - PSL格式比对结果
BLAT/PSL格式的比对结果，包含详细的比对信息。

**PSL格式主要列含义：**
```
列1: matches            匹配的碱基数
列2: misMatches         错配的碱基数
列3: repMatches         重复序列匹配数
列4: nCount             N碱基数
列5: qNumInsert         查询序列插入数
列6: qBaseInsert        查询序列插入碱基数
列7: tNumInsert         目标序列插入数
列8: tBaseInsert        目标序列插入碱基数
列9: strand             比对链方向 (+/-)
列10: qName             查询序列名称
列11: qSize             查询序列长度
列12: qStart            查询序列起始位置
列13: qEnd              查询序列结束位置
列14: tName             目标序列名称 (染色体)
列15: tSize             目标序列长度
列16: tStart            目标序列起始位置
列17: tEnd              目标序列结束位置
列18: blockCount        比对块数
列19: blockSizes        各比对块大小
列20: qStarts           查询序列各块起始位置
列21: tStarts           目标序列各块起始位置
```

### 2.3 断点分析文件

#### `*.AllBreakpoints.tsv` - 所有断点结果
包含该区域检测到的所有断点位置。

**列含义：**
```
列1: sampleID           样本ID
列2: chr                染色体名称
列3: strand             链方向
列4: pointGroup         断点分组类型
列5: Group              断点组别
列6: readsCount         支持该断点的reads数
列7: pos                断点位置
列8: type               断点类型标识
```

**断点类型说明：**
- `nu_Tend_Bleft`: 核基因组末端-BLAST左端
- `nu_Tstart_Bright`: 核基因组起始-BLAST右端  
- `mt_Tend`: 线粒体末端
- `mt_Tstart`: 线粒体起始

**示例：**
```
HG001	chr1	+	nu_Tend_Bleft	nuleft	2	634078.0	all
HG001	chrM	+	mt_Tstart	mt_Tstart	1	8165.0	all
```

#### `*.ConfidentBreakpoints.tsv` - 置信断点结果
经过过滤后的高置信度断点，格式与AllBreakpoints.tsv相同，但仅包含满足置信度标准的断点。

#### `*.Breakpoints.old.tsv` - 旧版断点格式
兼容旧版本的断点结果格式。

### 2.4 区域特异性文件

#### `PREFIX.psl` - 特定区域PSL文件
从总PSL文件中提取的特定候选区域的比对结果，其中PREFIX格式为：
```
{sampleID}_{chr}.{start}.{end}
例如：HG001_chr1.633396.634413
```

## 3. 分析流程总结

1. **输入**：全基因组测序BAM文件
2. **预处理**：提取线粒体相关的不一致读对和分裂读
3. **聚类**：识别潜在的NUMT插入区域
4. **序列提取**：获取候选区域的所有reads序列
5. **重新比对**：使用BWA-MEM进行全基因组比对
6. **断点检测**：分析比对结果确定精确的插入断点
7. **结果过滤**：生成高置信度的NUMT注释结果

每个检测到的NUMT都会生成一套完整的分析文件，包括比对详情和断点注释，便于后续验证和分析。
